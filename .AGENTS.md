# Hackathon Rebuild Plan (Next.js App Router + Tailwind)

## 0) Project Overview

### Goal
Rebuild the project from scratch while keeping the **overall layout feel** and a **single accent/point color**.  
The service links **university courses** and **job postings** through **pre-generated mock relationships** (no AI similarity at runtime).

### Pages (Target)
1. **Course List (Home)**  
   - Render a simple list of courses from `courses.json`
   - Clicking a course navigates to Course Detail

2. **Course Detail**  
   - Desktop split layout
   - Left: selected course detail
   - Right: related job postings list
   - Top-right: switch to Graph View

3. **Job Detail**  
   - Desktop split layout
   - Left: selected job detail
   - Right: related courses list
   - Top-right: switch to Graph View

4. **Graph View**
   - Precomputed graph data (`graph.json`)
   - Render an Obsidian-like graph view centered on one node (depth = 2)
   - Depth rules:
     - center = job: job → course → job
     - center = course: course → job → course

### Tech Stack
- Next.js **App Router**
- Tailwind CSS only
- Static JSON mock data
- Graph view: lightweight radial (concentric) layout (fast, no heavy graph libs)

### Proposed Routes (App Router)
- `/` → Course List
- `/courses/[courseId]` → Course Detail
- `/jobs/[jobId]` → Job Detail
- `/graph/[type]/[id]` → Graph View (`type` is `course` or `job`)

### Data Location
- `src/data/courses.json`
- `src/data/jobs.json`
- `src/data/graph.json` (generated later)

### Connection Rule
Connections are **pre-generated** and stored directly in JSON:
- Course has `relatedJobIds: string[]`
- Job has `relatedCourseIds: string[]`
Both sides must be consistent.
